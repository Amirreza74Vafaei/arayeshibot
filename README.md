# ربات فروشگاهی تلگرام (Telegram Shop Bot)

این پروژه یک ربات فروشگاهی کامل برای تلگرام است که با پایتون، `aiogram` و `FastAPI` ساخته شده است. این ربات به کاربران امکان می‌دهد محصولات را مشاهده کنند، به سبد خرید اضافه کنند و سفارشات خود را ثبت کنند. همچنین یک پنل ادمین تحت وب برای مدیریت فروشگاه ارائه می‌دهد.

---

## 🌟 ویژگی‌ها

### قابلیت‌های کاربر
- نمایش دسته‌بندی و محصولات به صورت صفحه‌بندی شده
- افزودن محصول به سبد خرید
- مشاهده و مدیریت سبد خرید
- فرآیند تسویه حساب چندمرحله‌ای (دریافت آدرس و تلفن)
- اعمال کد تخفیف
- ثبت سفارش با روش "پرداخت درب منزل"
- مشاهده تاریخچه سفارشات

### قابلیت‌های پنل ادمین (API)
- احراز هویت امن با JWT
- مدیریت کامل محصولات (CRUD)
- مدیریت کامل دسته‌بندی‌ها (CRUD)
- مشاهده و فیلتر سفارشات
- تغییر وضعیت سفارش
- ایجاد و مدیریت کدهای تخفیف
- گزارش‌گیری فروش در بازه‌های زمانی مشخص

---

## 🛠️ پشته فناوری

- **زبان:** Python 3.11+
- **فریم‌ورک ربات:** `aiogram`
- **فریم‌ورک وب (پنل ادمین):** `FastAPI`
- **پایگاه داده:** PostgreSQL (برای پروداکشن) / SQLite (برای توسعه محلی)
- **مایگریشن دیتابیس:** `Alembic`
- **اعتبارسنجی داده:** `Pydantic`
- **کانتینرسازی:** `Docker` و `Docker Compose`

## 🚀 راه‌اندازی و نصب

### پیش‌نیازها
- Docker و Docker Compose
- Python 3.11+ (برای توسعه محلی)

### ۱. کلون کردن پروژه
```bash
git clone <repository_url>
cd <repository_directory>
```

### ۲. ایجاد فایل تنظیمات
یک فایل `.env` با کپی کردن از نمونه ایجاد کنید.
```bash
cp .env.example .env
```
سپس مقادیر داخل `.env` را با اطلاعات خود، به‌خصوص `BOT_TOKEN` و `ADMIN_TELEGRAM_ID`، پر کنید.

## 🏃‍♂️ اجرای پروژه

### روش اول: استفاده از Docker (روش پیشنهادی برای پروداکشن)
این روش تمام سرویس‌ها (ربات، پنل وب، دیتابیس PostgreSQL و Redis) را راه‌اندازی می‌کند.

۱. **ساخت و اجرای کانتینرها:**
```bash
sudo docker compose up --build -d
```
۲. **اعمال مایگریشن‌های دیتابیس:**
برای اولین اجرا، باید جداول دیتابیس را ایجاد کنید.
```bash
sudo docker compose exec bot alembic upgrade head
```
۳. **ایجاد کاربر ادمین اولیه:**
یک کاربر ادمین برای ورود به پنل ایجاد کنید.
```bash
sudo docker compose exec web python scripts/create_admin.py <username> <password>
```
- **پنل ادمین** اکنون در آدرس `http://localhost:8000` در دسترس است.
- **مستندات API** (Swagger) در آدرس `http://localhost:8000/docs` قرار دارد.

### روش دوم: اجرای محلی با SQLite (برای توسعه)
این روش برای توسعه سریع و بدون نیاز به Docker مناسب است.

۱. **نصب وابستگی‌ها:**
```bash
pip install -r requirements.txt
```
۲. **اعمال مایگریشن‌ها:**
این دستور پایگاه داده `telegram_shop.db` را ایجاد و جداول را در آن می‌سازد.
```bash
alembic upgrade head
```
۳. **ایجاد کاربر ادمین:**
```bash
python scripts/create_admin.py <username> <password>
```
۴. **اجرای پنل ادمین:**
```bash
uvicorn src.admin_panel.main:app --reload
```
۵. **اجرای ربات:**
در یک ترمینال دیگر، ربات را اجرا کنید.
```bash
python -m src.bot.main
```

## Utility Scripts

- **`scripts/seed_db.py`**: این اسکریپت دیتابیس را با داده‌های نمونه (محصولات و دسته‌بندی‌ها) پر می‌کند. برای اجرای آن در محیط محلی:
  ```bash
  python scripts/seed_db.py
  ```
- **`scripts/create_admin.py`**: برای افزودن کاربران ادمین جدید استفاده می‌شود.
  ```bash
  python scripts/create_admin.py <new_username> <new_password>
  ```
