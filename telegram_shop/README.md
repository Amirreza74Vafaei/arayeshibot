# ربات فروشگاهی تلگرام با پرداخت درب منزل (COD)

این یک پروژه ربات تلگرامی کامل برای یک فروشگاه آنلاین است که با زبان Python و فریم‌ورک `aiogram` ساخته شده است. ویژگی اصلی این ربات، پشتیبانی کامل از فرآیند **پرداخت در محل (Cash on Delivery)** است و نیازی به درگاه پرداخت آنلاین ندارد.

## ✨ ویژگی‌ها

### قابلیت‌های کاربری
- **منوی اصلی ساده**: دسترسی آسان به دسته‌بندی‌ها، جستجو، سبد خرید و سفارشات.
- **مشاهده محصولات**: نمایش دسته‌بندی شده محصولات همراه با عکس، نام، قیمت و موجودی.
- **سبد خرید کامل**: امکان افزودن، حذف و ویرایش تعداد محصولات در سبد خرید.
- **فرآیند ثبت سفارش روان**: دریافت اطلاعات گیرنده (نام، شماره تماس، آدرس) به صورت مرحله به مرحله.
- **شفافیت هزینه**: نمایش هزینه کل و هزینه ارسال (قابل تنظیم توسط ادمین) قبل از ثبت نهایی.
- **پیگیری سفارش**: مشاهده وضعیت سفارش‌های قبلی (`جدید`, `تأیید شده`, `ارسال شده` و ...).
- **اطلاع‌رسانی خودکار**: دریافت پیام در هر مرحله از تغییر وضعیت سفارش.

### پنل مدیریت (داخل تلگرام)
- **دسترسی امن**: پنل مدیریت فقط برای ادمین‌های تعریف شده در فایل `.env` قابل دسترس است.
- **مدیریت کامل محصولات**: افزودن محصول جدید (با نام، توضیحات، قیمت، موجودی و تصویر)، لیست کردن و حذف محصولات.
- **مدیریت سفارش‌ها**: مشاهده سفارش‌های جدید، تأیید، علامت‌گذاری به عنوان "ارسال شده"، و لغو سفارش‌ها.
- **اطلاع‌رسانی به ادمین**: ارسال پیام به کانال مدیریت در هنگام ثبت یک سفارش جدید.
- **تنظیمات فروشگاه**: قابلیت تنظیم هزینه ارسال از طریق دستورات مدیریتی.

## 🛠️ معماری و تکنولوژی‌ها
- **زبان**: Python 3.10+
- **فریم‌ورک ربات**: `aiogram` (نسخه 3.x)
- **پایگاه داده**: `SQLAlchemy` ORM با پشتیبانی از SQLite (پیش‌فرض) و PostgreSQL (قابل مهاجرت).
- **پیکربندی**: استفاده از فایل `.env` برای مدیریت متغیرهای محیطی مانند توکن ربات و شناسه‌های ادمین.
- **ساختار ماژولار**: کد به صورت ماژولار در پوشه‌های `handlers`, `db`, `keyboards`, `utils` سازماندهی شده تا توسعه و نگهداری آن آسان باشد.

## 🚀 راه‌اندازی و نصب

مراحل زیر را برای راه‌اندازی ربات دنبال کنید.

### ۱. پیش‌نیازها
- Python 3.10 یا بالاتر
- `pip` برای نصب پکیج‌ها

### ۲. کلون کردن پروژه
```bash
git clone <URL_REPOSITORY>
cd telegram_shop
```

### ۳. نصب وابستگی‌ها
یک محیط مجازی ایجاد و فعال کنید (توصیه می‌شود):
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```
سپس پکیج‌های مورد نیاز را نصب کنید:
```bash
pip install -r requirements.txt
```

### ۴. پیکربندی متغیرهای محیطی
یک فایل به نام `.env` در ریشه پروژه (کنار فایل `requirements.txt`) بسازید. می‌توانید فایل `.env.example` را کپی کرده و مقادیر آن را ویرایش کنید.
```bash
cp .env.example .env
```
سپس فایل `.env` را با اطلاعات خود پر کنید:

- `BOT_TOKEN`: توکن ربات خود را که از [BotFather@](https://t.me/BotFather) دریافت کرده‌اید، وارد کنید.
- `ADMIN_IDS`: شناسه عددی اکانت‌های تلگرامی که به پنل مدیریت دسترسی خواهند داشت را وارد کنید. برای پیدا کردن شناسه خود، از ربات‌هایی مانند [userinfobot@](https://t.me/userinfobot) استفاده کنید. اگر چند ادمین دارید، شناسه‌ها را با کاما (`,`) جدا کنید.
- `ADMIN_CHANNEL_ID` (اختیاری): شناسه کانال یا گروهی که می‌خواهید اعلان‌های سفارش جدید در آن ارسال شود. ربات باید در آن کانال ادمین باشد.

### ۵. ساخت و مقداردهی اولیه پایگاه داده
برای ساخت جداول پایگاه داده (SQLite) و افزودن چند محصول و دسته‌بندی نمونه، اسکریپت زیر را اجرا کنید:
```bash
python init_db.py
```
این دستور یک فایل `telegram_shop.db` در ریشه پروژه ایجاد می‌کند.

### ۶. اجرای ربات
اکنون می‌توانید ربات را اجرا کنید:
```bash
python bot.py
```
اگر همه مراحل را به درستی انجام داده باشید، ربات شما آنلاین شده و به دستورات پاسخ می‌دهد.

## 🎛️ دستورات ادمین
برای دسترسی به پنل مدیریت، به ربات خود بروید و دستور `/admin` را ارسال کنید. یک کیبورد جدید با گزینه‌های مدیریتی برای شما نمایش داده می‌شود.

- **افزودن محصول**: از دکمه "➕ افزودن محصول" استفاده کنید و مراحل را دنبال کنید.
- **لیست محصولات**: از دکمه "📋 لیست محصولات" برای دیدن ID محصولات استفاده کنید.
- **مدیریت سفارش‌ها**: با کلیک روی "📦 مدیریت سفارش‌ها" می‌توانید سفارش‌ها را بر اساس وضعیت فیلتر کرده و مدیریت کنید.
- **تنظیم هزینه ارسال**: برای تنظیم هزینه ارسال از دستور `/set_shipping_cost <مبلغ>` استفاده کنید. مثال:
  ```
  /set_shipping_cost 25000
  ```
